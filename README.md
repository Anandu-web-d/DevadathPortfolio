# DevadathPortfolio — Cinematic Portfolio | DeepInTales

An award-level, cinematic personal portfolio for **Devadathan R**, professional Video Editor and Visual Storyteller.

## Features
- **Hero Staging**: Layered typography overlap with `mix-blend-mode: screen`, centered subject composition, and studio circular halo disc.
- **Interactive Character Reveal**: Smooth feathered cursor reveal and Pixar 3D interpretation toggle.
- **Flash-Card Project Deck**: 3D tilt cards, category filtering (All Work, Videos, Posters, Photography), and high-resolution media previews.
- **Integrated Video Player**: HTML5 video playback with responsive scrub controls, duration timestamps, and Instagram embed support.
- **Glassmorphism & Cinematic Design**: Translucent dark charcoal surfaces, restrained backdrop blur, and warm amber accents.

## Tech Stack
- **React 19** + **TypeScript**
- **Vite 8**
- **Vanilla CSS3** (Custom design system, hardware-accelerated transforms)

## Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
